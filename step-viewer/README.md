# STEP 뷰어

STEP(.stp/.step) 파일을 3D로 보고 외형 치수·부피·질량·면 구성·원형 모서리 지름을 보여 주는 윈도우용 로컬 프로그램입니다.

## 파이썬 없이 쓰기 (권장)

1. 이 저장소의 **Releases → `stepviewer-latest`** 에서 `STEPViewer-win64.zip` 을 받습니다.
2. 원하는 로컬 폴더(예: `C:\STEPViewer`)에 압축을 풉니다. USB나 네트워크 드라이브에서 바로 실행하지 마세요.
3. `STEPViewer.exe` 를 실행하면 메인 창이 뜹니다.
4. STEP 파일 더블클릭으로 열려면 `파일연결_등록.bat` 을 한 번 실행합니다. (해제: `파일연결_해제.bat`)

배포판은 `step-viewer` 폴더가 바뀔 때마다 GitHub Actions(윈도우 서버)에서 자동으로 만들어지고, 자체 점검을 통과해야 올라갑니다.

## 파이썬으로 실행하기

- `step_viewer_설치.bat` : 파이썬과 라이브러리(cadquery-ocp, pyvista)를 설치합니다.
- `step_viewer_run.bat` : 실행
- `step_viewer_파일연결_등록.bat` / `_해제.bat` : 더블클릭 연결
- `step_viewer_exe만들기.bat` : 이 PC에서 직접 exe 묶음 만들기 (`prune_vtk.py` 필요)

## 화면 구성

한 창 안에 위쪽 명령 도구 모음(열기·패널·색상·정밀 보정), 왼쪽 패널(부품 정보 / 이전 기록 / 밀도), 가운데 3D 화면과 그 위 보기 도구(화면 맞춤·등각·정면·윗면·우측면·표시 스타일·단면 X/Y/Z·치수·외곽 상자·자동 회전), 아래 상태 표시줄로 구성됩니다. (`--classic` 옵션으로 예전 두 창 방식 실행 가능)

## 3D 창 단축키

왼쪽 드래그 회전 · 휠 확대 · Shift+드래그 이동 · Space/A 자동 회전 · ↑↓ 회전 속도 · F 화면 맞춤 · V 정면 · T 윗면 · R 우측면 · I 등각 · W 와이어프레임 · S 음영 · B 외곽 상자 · M 거리 측정 · Esc 측정 지우기 · F9 패널 · Ctrl+O 열기

측정: 마우스를 **선·호·R·면**에 올리면 아래 상태 표시줄에 그 치수(직선 길이·원 Ø·호 R과 각도·원통 Ø·필렛 R 등)가 바로 나오고 해당 요소가 주황색으로 강조됩니다. 공차 정보는 STEP(AP214)에 없어 표시하지 않습니다.

요소 거리 측정(오토캐드/솔리드웍스 방식): **M**(또는 보기 도구의 분홍 아이콘)으로 측정 모드를 켜고 요소 두 개를 차례로 클릭합니다. 마우스를 올리면 선택될 요소가 주황색으로 미리 보이고, 선택한 요소는 분홍색으로 표시됩니다.

| 선택 | 결과 |
|---|---|
| 직선 ↔ 직선 | 평행이면 선 간 수직 거리, 아니면 사잇각 + 최소 거리(연장선 기준) |
| 원/호 ↔ 원/호 | 중심선(축) 간 거리, 같은 축이면 '동축' |
| 원통면(구멍 안쪽 벽) | 그 중심선으로 취급 |
| 직선 ↔ 원/호 | 원 중심(중심선)에서 직선까지 수직 거리 |
| 평면 ↔ 평면 | 평행이면 면 간 거리, 아니면 사잇각 |
| 직선 ↔ 평면 | 평행이면 거리, 아니면 사잇각 |
| 원/호 ↔ 평면 | 원 중심에서 평면까지 거리 |
| 꼭짓점 ↔ 무엇이든 | 수직 거리 |

측정하면 왼쪽 **측정** 탭에 자세한 값이 나옵니다(값 더블클릭 = 복사): 선택 요소의 좌표(꼭짓점·원 중심·시작/끝점), 길이·둘레·호 길이, 지름, **면적**, 중심선/법선 방향, 결과와 ΔX/ΔY/ΔZ, 그리고 원본 곡면 기준 **최소 거리**(두 요소에서 가장 가까운 두 점, 회색 점선)와 면 두 개를 고르면 면적 합계. 마우스를 면에 올리면 면적, 곡선·호에 올리면 길이도 함께 나옵니다.

원·원통면은 중심선이 점선으로 그려지고, 치수선 끝이 선분 밖이면 연장선이 회색 점선으로 표시됩니다. 상태 표시줄에 결과·ΔX/ΔY/ΔZ·선택한 두 요소가 나옵니다. 세 번째 클릭은 새 측정, Esc 지우기.

분석 도구: **X** 단면 보기(누를 때마다 X→Y→Z 평면→끔, 파란 평면을 마우스로 끌어 위치 이동) · **D** 도면식 치수 표기 켜기/끄기(평소엔 꺼져 있고, 켜면 전체 외형·구멍 Ø 치수선 표시)(전체 외형 가로·세로·높이 치수선, 구멍·축 지름 Ø — 가리키는 원을 같은 색 고리로 표시(가려진 부분은 연하게), 같은 지름은 `n×Ø` 로 묶고 해당 원 전부에 같은 색 고리. 왼쪽 패널의 지름 항목을 누르면 그 지름만 강조. STEP에 공차 정보가 없어 공차는 표기하지 않음)

## 참고
